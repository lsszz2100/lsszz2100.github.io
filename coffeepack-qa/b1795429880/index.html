Coffee Pack

Sort the drinks. Pack the boxes.

How to play

Drag a cup into a box

Drinks arrive on the tray. Drag one up into an empty holder box — or tap the cup, then tap a box.

One box, one drink

A box only takes the same drink again. Use empty boxes to start a new flavour.

Six of a kind = packed

Fill a box with six cups of one drink and it packs itself away, freeing the box.

↶ ⇄ ⌫

Undo, shuffle, empty a box

Stuck? Take a move back, reshuffle the queue, or send a box back to the tray before the timer runs out.
