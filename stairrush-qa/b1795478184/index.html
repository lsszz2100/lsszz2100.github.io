How to play

  1. Tap LEFT or RIGHT to jump to the next stair. The next stair glows.
  2. A wrong direction makes you fall. There is no undo — the next run starts in a second.
  3. The gauge drains all the time. Every stair refills it; higher floors drain it faster.
  4. Every 10 correct steps in a row is FEVER: double points. Golden stairs give coins.
  5. In Stages you climb a set number of floors as fast as you can for up to 3 stars.
