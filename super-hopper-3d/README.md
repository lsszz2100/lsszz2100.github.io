# 🍄 Super Hopper 3D

버섯 친구 **호퍼**와 떠나는 3D 플랫포머 웹 게임입니다. 브라우저에서 바로 실행되며 PC와 모바일을 모두 지원합니다.

**플레이:** https://lsszz2100.github.io/super-hopper-3d/

## 스테이지

| 스테이지 | 이름 | 테마 | 특징 |
| --- | --- | --- | --- |
| 1 | 초원 입문 코스 | Sunny Meadows | 점프·코인·물음표 블록·첫 적 밟기·골인 깃발 |
| 2 | 하늘 다리 코스 | Sky Bridge | 구름 발판, 좌우·상하·앞뒤로 움직이는 발판, 스프링, 별 수집 |
| 3 | 용암 성채 챌린지 | Lava Citadel | 용암 강, 타이밍 발판, 좁은 다리, 연속 밟기, 최종 골인 |

각 스테이지에는 **코인**, **별 3개**, **체크포인트**, **하트 3개**, 제한 없음 / 타이머 기록이 있습니다.
스테이지를 클리어하면 다음 스테이지가 열리고, 최고 기록과 수집한 별이 브라우저(localStorage)에 저장됩니다.

## 조작

### PC
- **WASD / 방향키** — 이동
- **Space** — 점프 (공중에서 한 번 더 = 2단 점프, 누르고 있으면 더 높이)
- **Shift** — 대시
- **마우스 드래그** — 카메라 회전 / **마우스 휠** — 거리 조절
- **Q / E** — 카메라 회전
- **R** — 스테이지 재시작 · **P / Esc** — 일시정지 · **M** — 소리 끄기

### 모바일
- 화면 왼쪽 **조이스틱** — 이동
- 오른쪽 **JUMP / DASH** 버튼 — 점프·2단 점프 / 대시
- 화면 드래그 — 카메라 회전

## 구현된 기능

- Three.js 기반 3D 로우폴리 / 툰 셰이딩 월드, 실시간 그림자, 하늘 셰이더, 구름, 떠 있는 섬
- 밟으면 납작해지는 몬스터, 아래에서 치면 튀어 오르는 물음표 블록, 회전하는 코인·별, 스프링, 움직이는 발판, 체크포인트, 골인 깃발
- 가변 점프 높이, 코요테 타임, 점프 버퍼링, 2단 점프, 공중 대시로 조작감 보정
- Web Audio API로 합성한 레트로 효과음과 스테이지별 칩튠 BGM (음소거 가능)
- 코인·착지·밟기·블록 파티클, 화면 흔들림, 클리어 폭죽
- 타이틀 화면, 스테이지 선택(순차 해금), HUD(코인·별·하트·타이머), 클리어/게임오버/일시정지 모달, 최고 기록 저장

## 기술 / 리소스

- **Three.js r170** — MIT License, `vendor/three.module.js`에 로컬 번들 (CDN 의존 없음)
- 모든 3D 모델·텍스처·사운드·UI는 외부 에셋 없이 코드로 직접 제작한 오리지널 (타사 IP 사용 없음)
- 빌드 도구 없이 정적 파일만으로 동작 (`index.html`, `styles.css`, `src/`, `vendor/`)

## 파일 구성

```
index.html          게임 페이지 / HUD / 모달 / 터치 컨트롤
styles.css          UI 스타일
src/main.js         엔진(씬·물리·카메라·이펙트·UI)
src/levels.js       스테이지 3종 데이터
src/audio.js        Web Audio 효과음·BGM 신시사이저
vendor/three.module.js  Three.js r170 (MIT)
```

## 로컬 실행

```bash
cd super-hopper-3d
python3 -m http.server 8000
# http://localhost:8000
```

ES 모듈을 사용하므로 `file://`로 열지 말고 로컬 서버로 실행하세요.
