# Neon Breach — Arena Protocol (web demo)

Playable browser build of the Android game (com.mrlee.neonbreach). Every model, texture,
sound and the soundtrack are generated in code; Three.js r170 is bundled locally (MIT).

Play: https://lsszz2100.github.io/neon-breach/
Desktop: WASD + mouse (click to lock the pointer), R reload, Shift dash, Space jump, 1-4 weapons.
Android: left stick, drag to aim, FIRE button.
